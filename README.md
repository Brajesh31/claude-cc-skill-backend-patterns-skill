# Cc Skill Backend Patterns

Backend architecture patterns, API design, database optimization, and server-side best practices for Node.js, Express, and Next.js API routes.

## Overview

This repository preserves the skill definition published in the AITMPL catalog and its available companion resources.

## Installation

Clone this repository into your Claude Code personal skills directory:

```bash
git clone https://github.com/Brajesh31/claude-cc-skill-backend-patterns-skill.git ~/.claude/skills/cc-skill-backend-patterns
```

On Windows, use `%USERPROFILE%\.claude\skills\cc-skill-backend-patterns` as the destination.

## Usage

Claude Code can load the skill when a request matches its description. You can also invoke it directly with `/cc-skill-backend-patterns`.
